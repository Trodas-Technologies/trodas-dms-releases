# Trodas DMS for Windows

Installers and updates for the Trodas DMS Windows app, published by CI from the main (private) repository. The app checks the latest release here for updates.

Download the newest `Trodas-DMS-Setup-<version>.exe` from **Releases**. It is unsigned for now: Windows may show *Windows protected your PC*; choose **More info**, then **Run anyway**.
